# Lesson 02: Iterables, Loops, and Conditionals

## Getting Started

Follow the steps below to download the code and run the `main_lesson.py` file.

---

## Prerequisites

- [GitHub Desktop](https://desktop.github.com/) installed on your computer.
- Python installed (preferably version 3.6 or higher).

---

## Steps to Download the Code

1. **Clone the Repository**:
    - Navigate to this repository page.
    - Click the green **`Code`** button.
    - Select **`Open with GitHub Desktop`**.
    - Choose a local path to save the repository and click **Clone**.

2. **Navigate to the Project Folder**:
    - Open the folder where the repository was cloned.
    - Locate the file `main_lesson.py` inside the `lesson_02_iterables_loops_conditionals` directory.

---

## Running the `lesson_02.py` File

1. **Open a Terminal or Command Prompt**:
    - Navigate to the directory containing `lesson_02.py`.

2. **Run the Python File**:

    Execute the following command:
    ```
    python main_lesson.py
    ```

    If you have multiple Python versions installed, you may need to use:
    ```
    python3 main_lesson.py
    ```

3. **Follow the On-Screen Instructions**:
    - You'll learn about Iterables, Loops, and Conditionals.
    - Missions will guide you through editing the `student_code.py` file live!
    - Save your changes and press **`r`** to reload and check your progress.
    - Complete all missions to unlock a special animated celebration!

---

## Troubleshooting

- If you encounter issues running the file, ensure Python is correctly installed and added to your system's PATH.
- Verify that you are in the correct directory where `main_lesson.py` is located.
- Ensure that `student_code.py` is present in the same folder.

---

Enjoy your Python adventure — and have fun learning Iterables, Loops, and Conditionals! 🚀
